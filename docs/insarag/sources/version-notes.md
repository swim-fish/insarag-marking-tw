## 撤離號音跨文件矛盾

S1 §6.4（p.52）及 S2 的 INSARAG Signalling 小節均寫撤離三短聲、每聲約 1 秒，持續重複至場址清空；S3 §5.2（p.22）檢核表寫三長聲。本資料的號音附錄與 SVG 採專門號音條文的一致規則，並揭露矛盾。正式演習前，由採用單位確認並公告一致的號音。
