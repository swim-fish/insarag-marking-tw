## 原檔完整性

[file-integrity.json](file-integrity.json) 記錄原件的檔案大小與 **SHA-256**，涵蓋 S1–S7 的保存原件及 U1。雜湊用於確認本機檔案與本次保存版本相同，**不是發布機關的數位簽章**。SVG 與規則對照另見 [manifest.json](../figures/manifest.json)。

Windows 複核方式：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'docs/insarag/sources/originals/operations-2020.pdf'
```
