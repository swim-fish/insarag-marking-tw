## 人工判讀與未驗證項目

`zhtw-mcp` 的「恢復」提示屬軟體介面 restore/recover 語境，與 Resume Operations 不同，已記錄來源與保留理由。「分區」提示屬作業系統 partition 語境，本冊指 INSARAG 的 Sector，同樣列為語境例外。部分全形標點旁的空白提示屬資訊層級，用於並列標記與來源欄位；不改寫識別碼或英文原名。語言報告中的 0 錯誤／0 警告不代表沒有資訊提示。

尚未執行實體印表機試印或正式現場演練驗收。一般名詞一致性、字數及提示詞檢查不能證明全部技術語意正確，也不屬 ASD-STE100 認證。本冊採用 2027 版（2027-01-01 生效）；新版平台內容以核對日所見為準，生效前後須再核對。
