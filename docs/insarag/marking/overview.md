# 標記總覽

基準版本：2020。來源：[S1，第 6.1–6.3 節，pp.41–51](../sources/README.md)。

| 類別 | 2020 指引地位 | 放置／用途 | 尺寸參考 |
| --- | --- | --- | --- |
| 一般區域標記 | 選用 | 街名、門牌、地標，協助辨識位置 | 未訂統一尺寸 |
| 建物方向標記 | 選用 | 外部面向、內部象限、樓層 | 未訂統一尺寸 |
| 警戒區標記 | 選用 | 作業區或禁入危險區 | 未訂統一尺寸 |
| 工作場址分流標記 | 必要 | 入口附近、外部最顯眼的位置 | 方框約 1.2–1.0 m；ID 約高 40 cm；隊伍與 ASR 約高 10 cm |
| 受困者位置標記 | 必要；依第 6.3 節情境使用 | 接近受困者實際所在位置的表面 | 約 50 cm |
| 快速清查標記（RCM） | 選用，須由 LEMA 決定啟用 | 清查完成的物件或明確界定區域 | 約 20 × 20 cm |

尺寸是**現場標記參考值**，不是 SVG 列印比例。原文方框尺寸寫作「approximately 1.2 to 1.0 metres」，未清楚指定寬高；本整理不把它改寫成精確的「寬 1.2 m × 高 1.0 m」。

材料可依現場選擇噴漆、工程蠟筆、貼紙或防水卡片；現行手冊要求顏色與背景形成明顯對比。圖庫使用橘色是教學配色，不是規定所有現場一律只能用橘色。[S1，pp.41、44–45、48、50](../sources/README.md)

## 先看形狀與位置，再看字母

| 同一字母的不同位置 | 意義 |
| --- | --- |
| 方框內 `C-5` 的 `C` | 2020 範例的 C 分區 |
| 方框下方的分流類別 `C` | 可能有生還者 |
| 菱形內 `C` | Clear：指定範圍已達全面搜尋標準，無生還者或罹難者留在原位 |
| V 下方 `D-1` | 該位置確認有 1 名罹難者仍待移出 |
| 方框下方的分流類別 `D` | 該場址僅有罹難者 |
| 菱形內 `D` | 已達全面搜尋標準，但仍有罹難者留在原位 |

上表為教學閱讀整理；規則分別見 [工作場址](worksite.md)、[受困者位置](victim.md) 與 [RCM](rapid-clearance.md)。其中 `C`／完成線均不代表建物結構安全；安全狀況仍需依現場評估判斷。
