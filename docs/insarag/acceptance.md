# 檢查與驗收清單

本清單供後續教材或演習採用單位複核。編製者的檔案檢查結果見 [verification.md](verification.md)；下列方框保留給驗收人員填寫，沒有將待決事項標為已通過。

## 規則與圖形

- [ ] 基準版次與核對日期明確，2020 與待生效新版未混用。
- [ ] Worksite ID 為本教材的 2020 編碼範例；2027 換版另核對 Team ID＋流水號。
- [ ] 工作場址方框內有 ID、隊伍、已完成 ASR、日期；危害在上、分流在下。
- [ ] 必要時箭頭指向實際場址、入口或受困者，沒有規定固定朝向。
- [ ] 完成線只在所有需要工作完成、判定無需再作業後使用；不等同結構安全。
- [ ] 分流只列 A–D，並與內部象限、RCM 的同字母區別。
- [ ] V 下的 L／D 為確認仍待移出人數；移出時劃掉舊值、留下新值。
- [ ] RCM 為菱形；C／D 的定義、LEMA 決定啟用、搜尋標準及範圍均有說明。
- [ ] 死亡受困者全部移出後在原 D 旁新增 C，不直接塗掉原 D。
- [ ] 建物正面朝下時，Side 2 左、3 上、4 右；A 左前、B 左後、C 右後、D 右前。
- [ ] Ground Floor 未誤寫為 Floor 1。
- [ ] 作業區水平警戒帶與禁入區交叉警戒帶清楚區別。

## 來源與檔案

- [ ] 每張圖可回查來源 ID、章節、印刷頁與 PDF 閱讀器頁。
- [ ] 官方 PDF、DOCX 原檔與使用者文字原文已保存，SHA-256 複核一致。
- [ ] 8 張 SVG 為向量圖形與可編輯文字，沒有內嵌點陣圖、外部字型下載或 script。
- [ ] SVG 文字、箭頭、刪改線與菱形能清楚辨識。
- [ ] Markdown／HTML 的本機連結有效，圖庫可直接離線開啟。
- [ ] 官方原文矛盾與使用者參考文字的修正點已揭露。
